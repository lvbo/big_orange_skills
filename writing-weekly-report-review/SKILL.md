## 使用到的日记位置及结构说明
- 回顾基于日记和晨间日记
  - 晨间日记是每日的早晨写，回顾一下昨天的内容。
  - 日记是记录这一天的工作与生活，基本上当天的信息都会在日记中体现出来。
- 晨间日记说明
  - 位置：journals-morning 目录下
  - 文件名说明：文件名的前缀为晨间日记当天日期 yyyymmdd 这种格式 
- 日记说明
  - 位置：journals 目录下
  - 文件名说明：前缀为晨间日记当天日期 yyyy-mm-dd 这种格式

## 回顾流程
1. 如果用户未说明是回顾哪周，查询当日的上周所在的周数，使用shell脚本的`date`确认今天的日期，推算出是哪周
2. 读取这一周所有的晨间日记和日记
3. 把工作上涉及的所有事情总结出来，涉及团队管理、团队规划、异常处理、学习、文档输出、人员沟通、团队建设、个人重点项目投入、个人在工作上重点事项推进
4. 同时给出你的洞察，作为本周我思考的输出来源
5. 最后加入一个章节：从更深层提炼一些值得认真思考的点
6. 把结果数据写到 journals-week 目录下，文件名格式 yyyy-Www，没有这个文件就创建，有这个文件的话，不要修改内容，只做追加
