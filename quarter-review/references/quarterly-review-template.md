# 季度回顾模板

将 `YYYY`、`Qn`、日期、生成时间和素材覆盖替换为真实值。不要保留括号中的写作提示。

## 篇幅预算

- 目标阅读时间：3～5 分钟。
- 一句话总结只写 1 句；30 秒摘要只写 3 条。
- 关键结果 3～5 条，每条不超过 2 句。
- 跨月规律最多 3 条；下季度优先事项固定为 3 项。
- 表格单元格保持短句。证据放在日期、月份或 WikiLink 中，不展开素材审计过程。
- 正文优先控制在约 1200～1800 个中文字符；证据不足时缩短，不用空泛内容填满额度。
