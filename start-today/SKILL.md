# 开始今天

依次调用现有 Skill 完成整套初始化，不在本 Skill 中重复实现模板、同步或工时计算规则。

## 工作流程

1. 调用 `obsidian-morning-daily-note`，创建或确认今日晨间日记和当日日记，并修复两者链接。
2. 仅当第 1 步已确认当日日记存在且可写时，调用 `today-tasks-add-to-obsidian`；后者负责通过统一同步流程写入 Calendar、Things Today，并刷新计划容量提醒。
3. 最后重新读取当天两个文件，确认：
   - `journals-morning/YYYYMMDD.md` 与 `journals/YYYY-MM-DD.md` 均存在；
   - 当日日记包含目标晨间日记链接；
   - `### 每日计划` 存在，Calendar/Things 同步步骤给出了可验证结果；
   - “每日投入”中的受管容量提醒与当前计划一致，或在不超过 9 小时时不存在。

## 失败与重复执行

- 某一步没有需要修改的内容属于正常 no-op，继续下一步并报告“已存在/已同步”。
- 如果晨间日记模板缺失，但当日日记已存在且链接问题不影响计划同步，可以保留第 1 步错误并继续第 2 步；不要谎称晨间日记准备成功。
- 如果当日日记不存在、不可写或结构无法安全修复，停止后续写入并报告阻塞原因。
- Calendar 或 Things 单一来源失败时，不把该来源报为同步成功；保留已安全完成的其他结果，并明确说明容量统计可能不完整。
- 重复运行必须保持幂等，不重复创建链接、计划条目或容量提醒。

## 结果报告

按“晨间日记 / 当日日记与链接 / Calendar / Things / 计划容量 / 最终验证”汇总各项为新增、已存在、无变化、失败或未执行。
