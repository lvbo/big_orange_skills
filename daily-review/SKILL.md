## 日记结构说明
- 第一行链接的page是我的晨间日记，一般在每天的早上回顾一下昨天的事情，做日回顾的时候也读取这个文件的内容做一下分析、总结
- 晨间日记在 journals_morning 目录下

## 回顾流程
1. 确定回顾日期：
   - 如果用户未说明是哪天，使用 shell 的 `date` 获取当前日期，并将昨天作为回顾日期
   - 如果用户指定了日期，使用用户指定的日期
2. 在`journals`目录下读取对应日期的日记，日记文件的命名格式`yyyy-mm-dd`
3. 把对应做的所有事情做结构化总结，对于时间的花费做一个统计及偏差分析
  - 对于每日计划中填写的数据做一下说明，我使用工作法
    - 🍅 表示预估一个番茄钟 25min
    - 🍉 表示预估半个番茄钟 15min
    - 🥔 表示实际花费一个番茄钟 25min
    - 🍠 表示实际花费半个番茄钟 15min
4. 给出一些提效的建议
5. 晨间日记的内容使用专门的一个章节做总结、分析
6. 把结果数据回写追加到对应日期日记的最后，不要修改日记的内容，只做追加

## 回顾模板
```markdown
## 每日回顾
### 一句话总结
使用简洁的语言，对回顾日期当天的所有工作做一个总体性的总结
### 投入分析
| 任务名称 | 预估工时 | 实际工时 | 偏差 |
|---|---|---|---|
|  |  |  |  |
### 晨间日记总结
对回顾日期当天的晨间日记做一个总结性的总结
### 提效建议
给出 1 至 3 条有效的提交建议，并说明这些建议背后所依赖的已有原理
```
